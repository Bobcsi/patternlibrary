KÉSZ HÍMZÉS KATALÓGUS

A weboldal kész, 6 mintával.

Fájlok:
- index.html = főoldal
- app.js = működés, keresés, szűrés, adatlap
- style.css = megjelenés
- data/motifs.json = minták adatai
- assets/ = SVG képek
- gcode/ = a meglévő G-code fájlok

GITHUB PAGES:
1. Csomagold ki ezt a ZIP-et.
2. A benne lévő fájlokat töltsd fel a GitHub Katalogus repository gyökerébe.
3. Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
4. A GitHub Pages által megadott webcímen lesz elérhető.

A QR-kód a weboldal aktuális címét kódolja, ezért a GitHub Pages-en megnyitva már a telefonról is használható.
